# DotPassport SDK Demo Application

Comprehensive testing and demonstration app for the DotPassport SDK.

## Overview

This React application demonstrates all features of the DotPassport SDK, including:
- API Client with all 7 methods
- 4 widget types (Reputation, Badge, Profile, Category)
- Theme variations (light/dark/auto)
- Screenshot capture for documentation

## Setup

### 1. Install Dependencies

Already done! Dependencies are installed.

### 2. Get an API Key

1. Visit [DotPassport Developer Portal](https://dotpassport.com/developers)
2. Sign up or log in to your account
3. Navigate to the API Keys section
4. Create a new API key
5. Copy the API key

### 3. Start Development Server

```bash
npm run dev
```

The application will be available at `http://localhost:5173`

### 4. Enter API Key

Once the app loads:
1. Navigate to the Control Panel on the home page
2. Enter your API key
3. The SDK client will be automatically initialized
4. You can now explore all demos and features
